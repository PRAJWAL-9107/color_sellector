# Color Changer Game

## Overview

Color Changer Game is a simple web-based JavaScript project that tests the user's luck and understanding of color-number mappings.
The application generates a random number between 1 and 12, and the user must enter a number in the input field.
If the entered number matches the generated number, the background color changes to the corresponding color for one second before the page automatically reloads.

## Features

* Interactive color selection interface.
* Random number generation using JavaScript.
* Dynamic background color changes.
* Automatic page refresh after a successful match.
* Simple and beginner-friendly design.
* Built using pure HTML, CSS, and JavaScript.

## How It Works

1. A random number from 1–12 is generated when the page loads.
2. The user enters a number in the input box.
3. The entered value is compared with the generated number.
4. If both values match, the background changes to the selected color.
5. After one second, the game resets automatically.

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
